# Smart Waste Management System

## Overview

The Smart Waste Management System is an AI and IoT-based project that helps improve waste collection by monitoring the fill level of waste bins. It aims to optimize waste collection schedules, reduce unnecessary trips, and promote cleaner, smarter cities.

## Features

* Real-time waste bin monitoring
* AI-based waste management
* User-friendly interface
* Efficient waste collection planning

## Technologies Used

* Python
* HTML
* CSS
* JavaScript
* Microsoft Azure
* IoT Concepts

## How to Run

1. Clone the repository.
2. Install the required dependencies using:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:

   ```bash
   python app.py
   ```
4. Open the application in your web browser.
